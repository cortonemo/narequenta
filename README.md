# Nárëquenta — Tales of the Waning

### 🪶 License & Authorship

Nárëquenta is a tabletop roleplaying game about beautiful erosion.

You start at your absolute peak. Every action costs you pieces of yourself.  
You don't level up. You refine. You scar. You flicker out.

Core ideas:
- You begin at 100% in every Facet of self.
- When you act, you **spend** from that Facet.
- You may choose to **scar** that Facet: permanently lower its maximum, but become more efficient using it in the future.
- Rest restores what remains of you, but never what you’ve already burned away.

This repo contains:
- `rules/` — the core mechanic and metaphysics.
- `playtest/` — sheets and quick references so people can run it.
- `logs/` — design notes and playtest feedback, dated.

Status: v0.1 (concept/playtest draft, not final).
